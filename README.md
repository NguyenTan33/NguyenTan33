#### ✨ Key Engineering Accomplishments:
- 💳 **Automated VietQR SePay Webhook Reconciliation**: Real-time payment matching in **2-3 seconds**, automatic HTML email invoices, fallback REST API polling, and 10-minute order auto-expiry inventory restoration.
- 📦 **Multi-Unit Inventory Management (Sales BOM)**: Solved stock desynchronization for case/box items sharing a single parent stock pool (`ParentProductId` & `UnitMultiplier`).
- 🏗️ **Clean Architecture Refactoring**: Refactored 10+ monolithic controllers into Thin Controller / Service Layer pattern with Interface dependency inversion.
- ⚡ **Non-blocking Behavior Analytics**: Tracked search keywords, dwell times, and rage clicks asynchronously via `Task.Run` & Beacon API without slowing down page rendering.
- 👛 **User Wallet & Smart Voucher Engine**: Automated instant refund wallet system on order cancellation & real-time optimal promo recommendation engine.
